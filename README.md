# DevOps Engineering Lab

Laboratório de Engenharia de Software e DevOps, com projetos colaborativos
de backend, APIs, bancos de dados, automação e CI/CD.

## Sobre o projeto

O DevOps Engineering Lab é um ambiente colaborativo para desenvolvimento,
experimentação e aplicação prática de conceitos de Engenharia de Software
e DevOps.

O laboratório reúne projetos desenvolvidos pela equipe ao longo das
atividades práticas, permitindo aplicar conceitos de desenvolvimento,
arquitetura, APIs, bancos de dados, testes, automação e integração contínua.

## Objetivos

- Desenvolver projetos de software de forma colaborativa;
- Aplicar boas práticas de Engenharia de Software;
- Desenvolver e consumir APIs;
- Trabalhar com bancos de dados;
- Aplicar testes automatizados;
- Praticar Git e GitHub;
- Trabalhar com Docker e ambientes reprodutíveis;
- Implementar pipelines de CI/CD;
- Aplicar práticas de segurança no ciclo de desenvolvimento;
- Documentar decisões técnicas e arquiteturais.

## Projetos

### SupportFlow

Sistema de gerenciamento de chamados desenvolvido como projeto inicial
do laboratório.

**Principais funcionalidades:**

- Cadastro de usuários;
- Autenticação;
- Criação de chamados;
- Consulta de chamados;
- Exclusão de chamados.

**Tecnologias:**

- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- Docker
- GitHub Actions

> A documentação específica, arquitetura e instruções de execução do
> SupportFlow estarão disponíveis no diretório do projeto.

## Organização

Os projetos são desenvolvidos de forma colaborativa, com divisão de
responsabilidades entre os integrantes e utilização de práticas de
controle de versão, revisão de código, testes e integração contínua.
